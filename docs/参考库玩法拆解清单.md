## 0. 一句话结论

这库里最值钱的不是「成人内容」，而是**三套成熟的结构**：

1. **《Yokai Art》**（就是 `植物大战僵尸H` 目录里那款）——一款和《星陨战线》同赛道的**成人向 PvZ 式塔防**，它的「编成 / 弱点 / 好感 / 多模式共用卡池」四件套，几乎是给这个项目量身写的参考答案。
2. **《XP Battle》**（`自走起`）——二次元自走棋，贡献了**「双轴羁绊」**这个成人向独有的构筑维度，以及「装备 3 合 1 + 商店刷新费递增 + Boss 三选一奖励」的经济模型。
3. **《Jack-o-nine-tails》**（`SLG`）——二十年老牌的硬核养成模拟，贡献了**「动词菜单 × 多维互相牵制的数值」**这套让"养成"不变成"点按钮"的方法论。

其余（Ren'Py 视觉小说、视频素材、壁纸）对**玩法**的增量很低，但你自己写的评测里有一批非常一致的**口味偏好**，那是比任何机制都重要的信息（见第 4 节）。

## 2. 逐个拆：它到底好玩在哪

### 2.1 Yokai Art（`植物大战僵尸H`）★★★

**定位**：和《星陨战线》同一条赛道——妖怪题材、和风、PvZ 式多路塔防（`SCENE_MAX_ROW_INDEX` 分行、`SamuraiZombie` 一类小怪、塔位/防线双塔类型），但把「角色」做成了长期养成对象。

从它的存档结构与类名可以读出的系统（证据：`SaveData/savedGames0.gd`、`Assembly-CSharp.dll`、`StreamingAssets/db/*.csv` 表名）：

| 它有的系统 | 证据（存档字段 / 类名 / 表） | 好玩在哪 |
| --- | --- | --- |
| **编成（Formation）** | `_formationTeamSetup`、`_formationLevelDict`、`_saveSelectFormation`、`UIFormationCustomizeDialog`、`FormationPerks` | 开局前不是"挑一张塔"，而是"组一队 + 订一条编成特性"。同一批角色，编成不同 = 打法不同 |
| **双货币 + 秘密商店** | `Money`、`Medal`、`SecretShopCountDown`、`SecretShopDiscount` | 小判/勋章分开，秘密商店限时且打折，制造"这次买不买"的犹豫 |
| **好感/心** | `HeartTableData`、`HeartBonusTableData`、`HeartLevel`、`HeartExp`、`UIBonusHeart` | 心等级**不给伤害**，只开剧情/立绘/CG——正好是你要的"解锁内容不解锁数值" |
| **弱点 + 逐步揭示** | `Weak_Fire/Ice/Lightning/Physical`、`WeaknessProgress`、`CanShowWeakness` | 敌人弱点**一开始不可见**，打够次数才揭示。情报本身变成一层玩法 |
| **灵魂/SoulLink** | `Soul`、`SoulCost`、`SoulRegenPerSec`、`SoulLinkAtkList`、`BP_CharacterTypeTiesMark` | 第二资源；塔与塔之间还有"链接增益"，不只是各自为战 |
| **多模式共用卡池** | `SCENE_MERGECARD` / `SCENE_RTD` / `SCENE_SURVIVAL` / `SCENE_GAMEPLAY`，各有 `_saveXxxCardDeck` | 同一批少女卡，能玩 4 种模式。**内容复用率的教科书** |
| **Boss 多血条** | `bShowBoss2HP`、`bShowBoss3HP`、`BossPhaseIndex`、`killedFujinPhase3` | 一条血一条血地破，阶段感比"百分比进阶段"强得多 |
| **图鉴/百科/教程快照** | `UIPediaScreen`、`Wiki`、`UnlockWikiOnCard`、`TutorialSnapTableData`、`unlockedComics` | 收集癖的落点，也是新玩家的自学入口 |
| **皮肤 + 裸体开关 + 小游戏** | `_ShownSkinList`、`TogglebNude`、`uiOppaiMinigameDialog`、`UICosplayScreen` | 成人向表现层，和玩法解耦，单独开关 |

**还有一条很关键的**：它有 `TalentTree`（`_SkillTreeDict`、`TalentTierList`、`UPGRADE_G1_TIER1`…）和 `levelStarDict`（每关星级）。也就是说它把「关卡评级」和「角色天赋树」两条成长线同时拉开，但**天赋是树状选择，不是线性加点**。

### 2.2 XP Battle（`自走起`）★★★

**定位**：VRM 3D 少女自走棋。玩法内核是"凑羁绊 + 合成 + 刷新商店"，成人向内容作为奖励层。

从 `Assembly-CSharp.dll` 里能直接读到它的羁绊类：

```
JobTitleTies:  ArcherTies  GuardTies  HealerTies  SoldierTies  WizardTies
CharacterTypeTies: MaidTies  SuccubusTies  SwimsuitTies  HugeTitTies
```

**这是全库最值得抄的一个设计**：*两套互相独立的羁绊轴*。

- 第一条轴是**职业**（弓/盾/奶/兵/法）——功能定位
- 第二条轴是**属性/癖好**（女仆/魅魔/泳装/巨乳）——成人向审美

两条轴各自独立计数、各自触发加成。结果就是：同一个 5 人阵容，可以"3 弓 + 2 女仆"，也可以"2 弓 + 3 泳装"，**强度差不多但观感完全不同**。对成人向游戏来说，这等于让「XP」本身变成了一种 Build 资源。

其他可读到的系统：

| 系统 | 证据 | 好玩在哪 |
| --- | --- | --- |
| 装备卡 3 合 1 | `ComMergeRoute`、`CheckMergeCondition`、`canMergedCard`、`RefreshMergedEquipments` | 合成的"确定性成长"，和抽卡的"随机"互补 |
| 三类卡池 | `BuffCard`、`TiesCard`、`EquipmentCard` | 每次三选一都有"这局要不要转流派"的岔路 |
| 商店刷新费递增 | `GetStoreRefreshCost`、`controlRefresh` | 用价格而不是次数来限流，比"免费 2 次重掷"更有经济感 |
| Boss 奖励分型 | `BossRewardSelectEquipmentCardList`、`BossSelectEquipmentCost`、`BossRewardTypeProb` | Boss 后不只是"给钱"，是给一次定向构筑机会 |
| 照片/裸体事件作为战斗奖励 | `CheckPhotoUnlock`、`BtnPhotoItem`、`CharacterNudeEvent`、`btnPunishGame` | 把成人向内容**挂到战斗里程碑**上，而不是单独开个画廊 |
| 星阶 + 等级 + 经验 | `StarLevelObject`、`GetNextLevelExp`、`GetLevelBattleCount` | 双层成长（本局等级 / 跨局星阶） |

### 2.3 Jack-o-nine-tails（`SLG`）★★

**定位**：QSP 引擎的老牌硬核奴隶养成模拟。它的 `json/menu_item.json` 直接暴露了它的"动词表"：

```
menu_slave_act / menu_slave_assig / menu_assistant_assig / menu_lesson / menu_tutor
menu_reward / menu_punish / menu_sex / menu_sex_edu / menu_demonstration
menu_domestic / menu_tidy / menu_prepare_meal / menu_take_bath / menu_take_drug
menu_accounting / menu_business / menu_cast_spell / menu_auspex / menu_tremedio …
menu_physical_development / menu_creative_development / menu_special_skills
```

**它好玩的地方不是内容，是"每个动词都同时改 5–8 个数值"**：体力、服从、畏惧、爱意、尊严、技能、健康……玩家做任何一个决定，都在别的地方付代价。所以它没有"最优解"，只有"这一周你想把她推向哪条线"。

对塔防的启示：**把"布防期"从"有钱就建"变成"有限行动点下的多目标取舍"**。

### 2.4 Dungeon of Revival（`3386556119`）★★

**定位**：MMD 模型的 3D 动作地下城（WASD + 跳跃 + 鼠标攻击）。

最有意思的是它的**状态机命名**：

```
StateReipu / StateReipuWake / StateKurusimi1-2 / StateSikosiko / StateNemuri
StateYogari / StateTamagoumi / StateKiba… / EROEVENT_POSY_RIMIT / EROEVENT_POSY_SPEED
```

也就是说，**成人向内容不是一段 CG，而是角色状态机里的一类"战斗状态"**——进入后改变动作、移动、出手。这类设计在成人向动作游戏里很成熟，但在**塔防**里几乎没人做。

## 3. PURPLE 那套「陪伴」值得单独拎出来

它是 Wallpaper Engine 壁纸，但设计比很多游戏细：

- **衣橱分三个标签**，切换只换列表不换人；点封面才换装
- **正序/倒序**每个衣橱分别记忆
- **轮播顺序/随机**，随机"每轮不重复、两轮交界不连续"
- **动态陪伴**：入场 → 循环待机；「单套循环」则重播入场
- **对白轮换**：连续 5 条普通对白后，下一次必出一条亲昵对白（不需要额外冷却）
- **"偶尔换一套"**：从定格开始计时，到点先播完离场再换；入场/离场不计入停留时长
- 自动收起 15 秒、设置可记忆

这套东西的启发不在"壁纸"，在于：**它把"重复观看"做成了不烦的节奏**——这正是《星陨战线》主菜单/结算页最缺的东西（现在是静态的）。

## 4. 你自己写的评测，暴露了很明确的口味

`3678454489` 里 41 篇评测，把「优点」和「差评」交叉看，信号非常一致。原文摘录（保留你的用词）：

**你会夸的：**

| 你夸的点 | 原话 |
| --- | --- |
| 节奏快、不折腾 | 「见面 5 秒即 OK」「不想看复杂的展开或麻烦的小游戏」 |
| 手感 | 「要以**恰到好处的速度**持续拖动」「操作简单到单手就能玩」 |
| 阶段化反馈 | 「各部位分别在 0~200 / 201~400 / … 有不同阶段的描述，**从一开始的青涩逐渐变为渴求**，很有成就感」 |
| 自由度高 | 「全地图、全员互动」「服装能一层一层脱」 |
| 反作业感 | 「小游戏过了前期就能跳过，不会出现枯燥的刷刷刷环节」 |
| 小体量高完成度 | 「这么低的价格可以做到这种程度吗」 |
| UI | 「UI 设计时尚，光是优秀的界面就能提升玩家的游戏意愿」 |

**你会骂的：**

| 你骂的点 | 原话 |
| --- | --- |
| 千篇一律 | 「所有场景的 H 内容都千篇一律，场景之间的区别仅在于体位略微不同」 |
| 作业感 | 「**作业感真的很重**」「一天 3 个接客时段…一直消耗时间拖到下午」 |
| 引导缺失 | 「游戏引导就几乎没有，摸了半天才知道怎么调整」 |
| UI 简陋 | 「UI 太简陋是最大缺点」 |
| 自由度虚高 | 「太过追求细部设定，反而大动作就只靠几个内建场景」 |
| 虎头蛇尾 | 「前期的盗摄非常有感觉…但最后的本番环节反而就看个水花就没了」 |

**这对《星陨战线》的直接翻译：**

1. 玩家已经能"跳过"的东西，就别做成必做（你的 8 波、布防期、剧情序章都已是可跳过结构，保持）。
2. **每个阶段必须有"文本/外观/反馈"三重变化**（对应你已有的 I–IV 阶：卡面有了、3D 有了，**阶段性台词/描述还没有**）。
3. 任何"每局都重复"的操作，要么能加速，要么能跳过。
4. UI 是你这类小体量产品的评分下限。

## 5. 提案总表（这是要你逐条拍板的部分）

类型：`玩法` / `表现` / `UX`
工作量：`S`（半天内）/ `M`（1–2 天）/ `L`（3 天+）
冲突：是否撞上你已定的红线（不做抽卡、不做数值型局外成长、单局 10–12 分钟）

### P0 · 建议优先（改动小、观感/构筑收益最大）

| # | 提案 | 来源 | 类型 | 量 | 冲突 | 具体做法 |
| --- | --- | --- | --- | --- | --- | --- |
| **A1** | **第二构筑轴：星轨标签** | XP Battle 双轴羁绊 | 玩法 | M | 无 | 现有只有「同类型融合」。给每名守卫再加一个**星轨**标签（月/霜/焰/灵），场上同标签 ≥2 / ≥3 时给**非数值向**的机制奖励（如"霜轨 2：命中叠加冻结层数上限 +1"）。不改塔的定位，只加"怎么排"的深度 |
| **A2** | **弱点揭示** | Yokai Art | 玩法 | M | 无 | 敌人加 火/冰/雷/物理 弱点；**开局不可见**，被打够 N 次才在血条下亮出图标，之后该敌人受到的对应伤害 +15%。把"情报"做成一层可感知的进度 |
| **A3** | **阶段台词/描述** | 你的评测（修女 5 阶段描述） | 表现 | S | 无 | I–IV 阶各写 2–3 句专属台词，融合升阶时弹一句；选中塔的面板里显示"当前阶段的一句话状态"。**纯文本，零系统风险**，但直接命中你夸过的"很有成就感" |
| **A4** | **铭文合成（3 合 1）** | XP Battle 装备合成 | 玩法 | M | 无 | 现在是"三选一"。加一条：**同稀有度 3 枚 → 1 枚高一档**。给玩家一个"垃圾铭文也有出口"的确定性通道，同时压低随机挫败 |
| **A5** | **商店刷新费递增** | XP Battle | 玩法 | S | 无 | 把「命运重掷 2 次 + 每 3 波 +1」改成"**首次免费，之后 20 / 35 / 50 星币**"，或两者并存但重掷也给钱通道。让经济决策更有连续感 |

### P1 · 值得做（结构性增量）

| # | 提案 | 来源 | 类型 | 量 | 冲突 | 具体做法 |

## 6. 明确不建议抄的

| 不建议 | 原因 |
| --- | --- |
| 抽卡 / 碎片 / 保底 | 你已明确否掉随机抽塔；买断制下抽卡只会让节奏变脏 |
| 好感度换伤害 | 直接违反你「局外解锁内容不解锁数值」的既定判断 |
| 每日任务 / 体力 / 广告 | 与买断制冲突（你文档里已写） |
| 把一局拉到 20 分钟 | 同上，已有结论 |
| 照搬 Yokai Art 的素材/文案/角色名 | 你卡面已在用它，**素材与 IP 必须停在"本地演示"**；系统可以学，资产不能搬。上线前按 `docs/Steam上线方案.md` 处理成人内容分区与素材授权 |
| 「全解锁开关」当唯一留存手段 | 你夸过它（"附带全解锁开关"），但它只适合"内容型"产品；塔防的留存应该是"下一局的新目标" |

## 7. 如果只做三件（我的建议）

```
A3 阶段台词/描述   （半天，零风险，直接命中你夸过的"成就感"）
A2 弱点揭示        （1–2 天，给战斗加一层可感知的信息）
A4 铭文合成 3 合 1 （1–2 天，给随机性兜底）
```

理由：这三件都不动 `game.js` 的核心循环，都能独立验收，且分别补上了「表现层的阶段感」「战斗层的信息层」「构筑层的确定性」——正好是你现在三个最薄的角。

第二批再做 **A1 星轨标签 + B2 心等级 + B4 Boss 双血条**，那是"从能玩到有味道"的一步。

## 8. 待你拍板

1. **A1 要不要做第二构筑轴？** 它会动 `data.js` 的守卫数据结构和融合判定，是目前提案里唯一"碰到核心"的一条。做，则融合深度立刻上一个台阶；不做，A3/A2/A4 完全独立可上。
2. **B1（守卫被魅惑/拘束）做到什么程度？** 我建议先只做「魅惑改目标 + 拘束停火点按解救」两种，绝顶先不做——它最容易滑向"纯 CG"。
3. **B5 布防期行动点**要不要试？这条会改节奏，风险最高，建议做成 `?actions=on` 的调试开关先跑几局看手感。
4. **C1 第二模式（合成）** 是不是这版不做？它是最大的时长杠杆，但也是最大的 UI 工量。
5. **成人向内容的"挂点"**：现在是纯画廊式，还是按 XP Battle 的做法挂到"战斗里程碑"上（C4）？后者留存更强，但会让内容解锁节奏绑死在难度上。
